# RPG-игра
Это простая RPG-игра, созданная в качестве лабораторной работы. Игровой процесс
представляет собой пошаговые бои между юнитами на поле. Юнитов можно произвольно размещать
и удалять.

## Выбор порождающего паттерна
Было решено реализовать паттерн **Фабричный метод** с созданием класса-фабрики на каждый
конкретный юнит для максимального соблюдения принципа Opec/Closed Principle из SOLID.
В проекте не встречаются ситуации когда нужно создавать связанные семейства объектов,
поэтому паттерн Абстрактная фабрика здесь не подходит.

В реализации есть базовый фабричный класс UnitFactory с абстрактным методом createUnit.
От этого класса наследуются классы с конкретными реализациями фабричного метода
(SwordsmanFactory, ChariotFactory, ...). Промежуточные классы-фабрики InfantryFactory,
RangedFactory, CavalryFactory не реализованы, т.к. в данном проекте внутри
этих классов нет никакой логики (поля или методы).




## 2 лабораторная ##

Для языков без перегрузки операторов (Java, Python - перегрузка возможна через магические
методы; C# - возможна; только Java не поддерживает) допускается реализовать методы с
именами, отражающими операцию, например: unit.collect(chest), unit.trigger(trap),
unit.empower(altar), unit.heal(source). В отчёте необходимо указать, что эти методы
являются эквивалентом перегрузки.
